# Historical material

This directory preserves the Java predecessor, prior reports, earlier figures, and version-specific release scripts. The scripts are snapshots for provenance and target the flat source layout and results tree of the original release. Use the original upload to reproduce those scripts in their historical layout. Current workflows are documented in the top-level README and use the installed Python package.

The active repository retains the V1.14 benchmark inputs and a curated set of original output records under `benchmarks/reference/`. The original upload still contains raw checkpoint series, XML exports, logs, and release duplicates. Historical data may contain original output paths, which identify their provenance.
